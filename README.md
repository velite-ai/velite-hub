# Velite Hub

Internal app for the Velite team: My Day, Raw & Packing Materials, Task Manager,
Business Compass (owners) and Admin. Compliance Tracker follows in Phase 2.

- **Screens:** React + Vite (`src/`)
- **Data & login:** Supabase (see `supabase/README.md`)
- **Hosting:** Coolify on the Hetzner server, built from this repo with the `Dockerfile` → hub.velite.in

## Making a change
Edit the code, commit to `main`. Coolify rebuilds and publishes automatically (about 1–2 minutes).
No manual copying of files and no `npm run build` on a PC is needed any more.

## Local preview (developers only)
```
npm install
npm run dev
```
